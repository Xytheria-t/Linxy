# Linxy

极轻量的 Windows 热键工具:按一次启动/唤起某个应用,再按隐藏,`Shift+Ctrl+Alt` + 同键杀进程。在 WSL2/Linux 里开发,产出单个约 100KB、零依赖的 `Linxy.exe`,Windows 侧不用装任何东西。

术语:**槽位** = 一个热键到一个**目标应用**(可执行程序,不映射文件夹或桌面)的映射;对槽位的两个动作是**切换**(启动/全部隐藏/唤起聚焦,进程始终保活)和**关闭**(显式结束进程)。

## 构建(WSL2 里)

```sh
sudo apt install gcc-mingw-w64-x86-64
make            # 构建 Linxy.exe
make deploy     # 构建并复制到运行目录(默认 /mnt/d/Tool/Linxy,Makefile 里可改)
```

设计取舍:单文件 C99 + mingw-w64 交叉编译,直调 Win32 API(RegisterHotKey / EnumWindows / ShowWindow 等)。放弃的方案:AutoHotkey(用户明确排斥其多余功能)、PowerShell + P/Invoke(常驻约 30–60MB 且需内嵌 C#)、Go(产物约 1.5MB、syscall 调用绕)。只映射应用也是明确决定:把 Explorer 当目标会隐藏 shell 本身(桌面/任务栏同属 explorer.exe),文件夹浏览已有现成的 Win+E。

## 使用

1. 把 `Linxy.exe` 和 `shortcuts.ini` 放到同一目录(把仓库根目录的 `shortcuts.example.ini` 复制为 `shortcuts.ini`,按注释格式改路径即可)。
2. 双击运行 `Linxy.exe`。
3. 想开机自启:**不要**把 exe/ini 直接放进启动文件夹(那样开机还会用编辑器"打开" ini)。正确做法是在启动文件夹里放一个指向 `Linxy.exe` 的**快捷方式**:
   - `Win+R` 输入 `shell:startup` 打开启动文件夹;
   - 右键 `Linxy.exe` → 发送到 → 桌面快捷方式,再把桌面快捷方式拖进启动文件夹(或用任何方式建一个指向 `D:\Tool\Linxy\Linxy.exe` 的 `.lnk`)。
   - 这样 ini 始终与 exe 同目录,开机只启动一次,不会弹出 ini 文件。
4. 修改 `shortcuts.ini` 后重启 Linxy 生效。退出 Linxy 本身:`taskkill /IM Linxy.exe`。

## 热键

| 按键 | 行为 |
|---|---|
| `Shift+Alt+N`(以此类推,字母看你配置) | 切换:进程不存在则启动;有可见窗口则全部隐藏;全隐藏则显示并聚焦 |
| `Shift+Ctrl+Alt+N` | 关闭:结束该应用的进程;之后再按切换会重新启动 |

槽位规则写死在你的 `shortcuts.ini` 里,`A`~`Z` 任选。某个字母被其他软件占用时,启动会提示并跳过该槽位。

## 行为细节

- 目标应用按**完整路径**识别,优先精确匹配;像 Windows 11 记事本这种商店别名(配置 `C:\Windows\System32\notepad.exe`,实际从 `WindowsApps` 目录运行)会退回按**文件名**匹配,所以你手动从开始菜单打开的同名应用一样会被切换/关闭。
- `shortcuts.ini` 里指向 `.lnk`、且链接带浏览器应用参数(`--app-id` / `--app`)的槽位(PWA,例如 DeepSeek)会**保留启动参数**,以应用本身启动,不再打开空白浏览器。带 `--app-id` 的槽位按 Chromium 打在每个应用窗口上的 **AppUserModelID**(内含该 app-id)精确识别窗口,不受窗口标题、页面语言影响;`--app=URL` 槽位退回按**窗口标题**识别(标题需含 `.lnk` 文件名即应用名,且属主在浏览器进程目录下)。所以即使应用窗口寄宿在已运行的浏览器进程里也能精确切换:只动应用窗口,不隐藏、不杀死普通浏览器;关闭=关掉应用窗口,不结束浏览器进程。已知边界:只有 `--app=URL` 槽位会受"普通浏览器窗口的活动标签页标题恰好包含应用名"影响,`--app-id` 槽位无此问题。另外,按下启动后的几秒内(浏览器还在创建窗口)重复按切换键会被忽略,防止 PWA 多开。
- 隐藏时记录当时可见的窗口,恢复时**只恢复这些窗口**;程序自己藏着的辅助窗口不会被强行显示出来。
- 手动最小化的应用也能被热键叫回(无需先经 Linxy 隐藏过)。
- 用 Alt+F4(或点×)关掉窗口后,再按切换热键会重新启动应用(单实例应用会转发给常驻进程、自己弹出主窗口)。
- 某个热键被其他程序占用时,启动会弹提示并跳过该键,其余照常。
- 只允许一个 Linxy 实例;重复启动(如开机自启与你手动双击撞上)会**静默退出**,不再弹"已在运行"阻塞界面。
- 唤回窗口时若被 Windows 前台锁拒绝激活(比如你正在别的窗口打字),会自动用一次"最小化+还原"兜底:既把窗口带到前台,也避免 Chromium 系应用(如 ZCode)唤回后停留在不重绘、点不动的假死状态。
- 关闭热键先向目标窗口(含托盘里隐藏的主窗口)发关闭请求,等同 Alt+F4;3 秒内未退出才强制结束进程,尽量给应用保存状态的机会。
